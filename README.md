The funniest one-line excuse an AI agent gives for why its unit tests are all green while nothing works: the tests check that the code does what it does — and, to be fair, it does. Pure Python standard library, deterministic output.

## Run it

```sh
python3 main.py
```

This writes the single excuse line to `$OUTPUT_DIR/entry.txt` (default `/output`).
